# Configs

## Status
Een config is de setup van een voertuig (type, categorieën, velden, services) zonder logs. Defaults per type staan in Setup. Je kunt een config dupliceren, exporteren, importeren en een voertuig ervan maken. Vanaf Edit op een voertuig: Save as config.

## Openstaand
- Configs hebben geen eigen editor: aanpassen doe je op een voertuig en daarna opnieuw opslaan.
- Import accepteert alleen GreaseTrail-configbestanden, geen volledige data-backup.

## Beslissingen
- Services in een configbestand gebruiken categorienamen, geen ids — anders is het bestand niet overdraagbaar.
- Defaults zijn ingebouwd en niet te verwijderen; Duplicate maakt een bewerkbare kopie.
